# 错题掌握、专业刷题与跨设备访问设计

## 目标

把课程与专业刷题改造成真正的“掌握后前进”机制，并让网站能在同一局域网的其他电脑访问。

## 学习规则

1. 选择错误答案后展示中文解析，但不得进入下一题。
2. 学生点击“重新作答”后回到同一道题，必须答对才能继续。
3. 任何答错过的题，即使当场已经纠正，也必须在本组末尾再次出现。
4. 末尾回刷中再次答错时，仍先当场纠正，并进入下一轮回刷。
5. 课程退出时保存完整掌握队列，恢复后不得绕过错题。

## 专业刷题

“今日练习”保留独立专业刷题入口。刷题页增加训练设置，可选择综合或单项主题、A2/B1/B2 难度和题量。结果页展示正确率、总作答、错误数和回刷轮次。课程与刷题共用同一套掌握队列，避免规则分叉。

## 情境配音

在部分核心词汇中保留原创的影视感情境台词和本地西语音频，明确标注为原创情境，不使用未授权电影原声。音频仍由浏览器直接加载项目内 MP3，因此离线构建和局域网访问均可播放。

## 跨设备访问

Vite 开发和预览服务器监听 `0.0.0.0:4173`。当前电脑使用 `127.0.0.1:4173`，同一局域网设备使用运行电脑的局域网 IP。互联网访问则部署 `dist/` 到静态托管服务；本地开发服务器不冒充公网部署。

## 验收

- 课程和专业刷题答错后都停留在原题。
- 当场答对后继续，末尾仍回刷该题。
- 退出并恢复课程后，错题队列仍存在。
- 专业刷题设置能真实改变题目集合。
- 情境配音返回可播放的 `audio/mpeg`。
- `0.0.0.0:4173` 监听成功，局域网地址能返回页面。
