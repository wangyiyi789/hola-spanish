# Hola 西班牙语学习模型设计规格

日期：2026-08-27

## 1. 产品目标

构建一套面向中文母语成年零基础学习者的、可完整体验的西班牙语前端学习模型。产品从 27 个西语字母开始，依次学习 9 种词性、12 个常用疑问表达和常用时态，并通过城市旅程、每日打卡、经验值、关卡解锁、图片联想、发音和句子应用形成可持续的学习闭环。

首版不包含账号、云端数据库或课程后台。所有核心体验必须在浏览器中真实运行，而不是只有静态页面。

## 2. 目标用户与设计原则

目标用户是从未系统学过西班牙语的成年人。中文承担解释和纠错，西班牙语承担目标内容和沉浸感。

设计遵循以下原则：

- 一屏一任务，避免同时展示过多语法概念。
- 先理解，再识别，再应用，最后通过短挑战巩固。
- 不因答错惩罚学习进度；错误必须转化为清楚的中文解释。
- 使用成年人的温暖绘本风，亲切、有故事感，但不幼稚。
- 用完整例句承载单词，让学习者理解词义、词性和实际语境。
- 所有激励都服务于坚持与复习，不用干扰学习的随机奖励。

## 3. 产品结构

产品采用“城市旅程主线 + 可调节每日任务辅助”的结构。每日节奏用于帮助用户开始学习，不限制当天的学习上限。

### 3.1 四座学习城市

1. **字母港**：27 个字母、5 个元音、Ñ、常见字母组合和基础发音。
2. **词语市集**：名词、冠词、代词、动词、形容词、副词、介词、连词、感叹词。
3. **问句广场**：qué、quién、cuál、cuánto、cómo、cuándo、dónde、adónde、de dónde、por qué、para qué、a qué hora。
4. **时态城**：现在时、正在进行时、现在完成时、简单过去时、过去未完成时、近期将来时、简单将来时、条件式和现在虚拟式。

四座城市在首页地图上全部可见。每座城市至少有一个能从开场做到结算的代表关卡；其他节点展示学习目标、先修关系和锁定状态。这样既呈现完整学习路径，又让首版范围保持在可高质量实现与验证的程度。

### 3.2 每日学习

首页显示每日目标、三项基础任务、本周学习足迹、连续打卡天数和一句西语。用户可选择轻量 10 分钟、标准 20 分钟、进阶 30 分钟、专注 45 分钟或沉浸 60 分钟，也可在完成目标后继续学习，不设置每日上限。

目标时长改变任务数量与推荐路线长度，不改变知识难度，也不以未完成高目标惩罚用户。用户完成当天第一节有效课程即可打卡；达到所选时长后获得当日目标完成标记。每日任务由以下内容组成：

- 一项复习任务；
- 一项当前路线的新课；
- 一项使用新词的句子练习。

完成关卡会获得 XP、更新今日进度和打卡状态，并在满足先修条件时解锁下一个节点。

达到每日目标后，首页切换为“继续探索”状态，提供沿当前路线继续、集中复习错题和自由浏览其他城市三种入口。连续学习期间保留上下文，关卡结算页直接推荐下一节，不强制返回首页。

## 4. 关卡学习闭环

每个代表关卡包含 4 至 6 个短步骤，总时长约 3 至 5 分钟：

1. 微讲解：用中文解释一个概念，展示核心西语内容。
2. 看图识别：把新词与统一风格插画建立联想。
3. 听音选择：使用西班牙语语音播放字母、单词或句子。
4. 拼词或填空：要求主动回忆，而不只是重复识别。
5. 例句应用：展示新词在完整句子中的用法，并标注相关词性。
6. 关卡挑战：三道综合题验证理解，完成后进入结算页。

关卡顶部显示当前步骤、总步骤和进度条。用户可退出并保留已完成步骤。

### 4.1 答题反馈

- 答对：显示 `¡Muy bien!`、简短知识解释、例句和本题 XP。
- 答错：保留用户答案，突出正确答案，并用中文解释两者差异。
- 用户必须主动点击“继续”，反馈不会自动消失。
- 答错不扣心、不回退地图进度；错题会进入复习记录。

### 4.2 代表关卡内容

- 字母关卡：Ñ 与 `niño`，例句 `El niño come pan.`。
- 词性关卡：通过同一句子的不同词语识别名词、动词和冠词。
- 疑问词关卡：根据生活场景选择 `qué`、`quién`、`dónde` 或 `por qué`。
- 时态关卡：比较现在时与简单过去时，例如 `Hoy estudio español.` 与 `Ayer estudié español.`。

## 5. 视觉与响应式设计

### 5.1 视觉方向

采用已确认的“温暖绘本”方向：

- 奶油色纸张背景；
- 陶土红作为主行动色；
- 苔藓绿表示正确、完成和可继续状态；
- 蜂蜜黄用于奖励与插画点缀；
- 深棕灰承担正文，确保成人界面的可读性；
- 标题使用具有人文气质的衬线字体，界面与中文正文使用清晰的无衬线字体。

狐狸 Lolo 是学习向导，负责提示、庆祝和错误鼓励。角色不能遮挡正文或答题控件。核心插画使用统一生成的手绘素材，真实按钮、文字、导航和进度仍由代码渲染。

已确认的视觉预览包括首页三栏布局和 Ñ 关卡的题目/反馈双状态。

### 5.2 页面布局

桌面首页使用三栏：

- 左栏：品牌、学习路线、今日练习、单词本和学习记录；
- 中栏：欢迎信息、当前章节卡片与城市学习路线；
- 右栏：可调节学习时长、每日计划、连续打卡和每日一句。

平板端收起右侧栏，将每日信息放到主内容下方。手机端采用单栏内容和底部导航；主要答题按钮固定在易触达区域，选项不依赖悬停状态。

## 6. 信息架构与组件边界

应用采用 React + Vite 单页架构，使用前端状态控制首页、课程与结算状态，不需要服务端路由。

主要模块：

- `AppShell`：全局导航、响应式布局和当前视图切换；
- `JourneyMap`：城市、节点、解锁状态和进入关卡；
- `DailyPlan`：每日目标、打卡和 XP 摘要；
- `LessonPlayer`：步骤推进、退出恢复和答案状态；
- `LessonStep` 组件族：讲解、图片选择、听音、填空、句子与挑战；
- `AnswerFeedback`：正确/错误说明和继续操作；
- `LessonComplete`：结算、奖励和下一节点；
- `VocabularyBook`：已接触词汇、词性、释义和例句；
- `ProgressStore`：读取、校验、迁移、备份和写入本地进度；
- `SpeechService`：封装浏览器西班牙语语音能力与降级提示。

课程内容放在独立数据模块中。视图组件消费统一的课程数据结构，不在 JSX 中重复硬编码整套课程。

## 7. 数据模型与状态流

### 7.1 课程数据

城市包含标识、标题、描述、主题和节点列表。节点包含先修节点、状态规则、预计时长、奖励和关卡标识。关卡包含步骤数组；每个步骤包含类型、题干、内容、选项、正确答案、解释、词汇和例句。

### 7.2 用户进度

本地进度包含：

- 数据版本号；
- 总 XP 和今日 XP；
- 每日目标分钟数与今日累计学习分钟数；
- 连续打卡天数与最近学习日期；
- 已完成和已解锁节点；
- 进行中的关卡与步骤；
- 已掌握词汇；
- 错题复习记录；
- 每日任务完成状态。

答题只更新当前关卡内存状态；完成关键步骤或退出关卡时持久化。完成关卡时以一次状态更新同时写入 XP、节点完成、解锁、词汇和打卡，避免局部成功造成显示不一致。

## 8. 本地持久化与安全恢复

首版使用带版本号的 `localStorage`。它不是云端同步，浏览器数据被用户清除后无法由应用自行恢复。

保存与恢复策略：

1. 读取主记录并进行结构与字段级校验。
2. 对可修复字段合并默认值，保留仍有效的 XP、打卡和节点记录。
3. 每次写入新主记录前，把上一次通过校验的记录保存为“最近可用备份”。
4. 主记录无法解析时尝试读取备份。
5. 主记录与备份都不可用时才创建初始进度，并向用户显示恢复提示。
6. 提供“导出学习记录”和“导入学习记录”。导入内容必须经过同一校验与迁移流程，不能直接覆盖当前状态。
7. 提供有二次确认的“重置学习记录”。

## 9. 发音与降级处理

发音优先使用 Web Speech API 的 `speechSynthesis`，语言设置为西班牙语，并在可用语音中优先选择 `es-ES` 或其他 `es-*` 语音。

若语音 API 或西语语音不可用：

- 发音按钮保持可见但呈不可用状态；
- 显示“当前浏览器暂不支持西语朗读”；
- 不阻塞答题、通关或获得 XP；
- 听音题允许切换为同知识点的文字识别题。

## 10. 可访问性与体验细节

- 所有核心操作可通过键盘完成，并有清晰焦点样式。
- 颜色不是正确/错误或锁定状态的唯一表达方式。
- 图像具有替代文本，装饰插画从读屏顺序中隐藏。
- 动效尊重 `prefers-reduced-motion`。
- 移动端触控目标不小于 44 像素。
- 西语字符与重音必须正确显示，包括 ñ、á、é、í、ó、ú、ü、¿ 和 ¡。

## 11. 验证标准

### 11.1 功能验证

- 可从首页进入四个代表关卡并完成一次完整学习闭环；
- 可在 10、20、30、45 和 60 分钟目标之间切换，并在达标后继续学习；
- 完成关卡后可直接进入推荐的下一节，连续学习不被每日目标截断；
- 正确和错误答案显示不同且准确的反馈；
- 退出后能恢复进行中的关卡；
- 完成关卡后 XP、打卡、节点与词汇本同步更新；
- 锁定节点不能绕过先修规则；
- 主记录损坏时能恢复备份；部分字段损坏时保留其他有效进度；
- 导出后重置并重新导入，可以恢复原进度；
- 无语音支持时仍可完成关卡。

### 11.2 视觉与响应式验证

- 对照已确认首页与关卡预览检查文案、三栏比例、配色、字体、圆角、插画位置和信息层级；
- 在桌面、平板和手机视口实际点击核心流程；
- 不出现裁切、横向溢出、按钮遮挡或难以阅读的文字；
- 手机端底部导航与主行动按钮易于触达；
- 动效关闭时功能与层级保持完整。

### 11.3 完成定义

构建、静态检查和自动化测试通过；核心流程在真实浏览器中完成；生成插画加载正常；视觉实现与已确认设计进行逐项对照，且不存在影响学习或交付质量的已知偏差。

## 12. 明确不在首版范围内

- 用户注册、登录和多设备云同步；
- 真实后端、课程管理后台和教师端；
- 社交排行榜、好友互动和付费体系；
- 语音识别评分或真人教师反馈；
- 为所有课程节点制作完整教学内容。

这些能力可在前端学习模型验证有效后继续扩展。
